Module maybe_zoom

A streaming filter that heuristically accepts connections that look like Zoom: on a UDP port in ZOOM_PORT_RANGE, with initial packets whose first byte matches one of Zoom’s observed payload-type markers.

Structs§

MaybeZoom
Accepts a connection once at least MAYBE_ZOOM_MIN_FRACTION of its first MAYBE_ZOOM_WINDOW payload-bearing packets (UDP, port in ZOOM_PORT_RANGE) start with one of ZOOM_FIRST_BYTES. Non-UDP or non-Zoom-port connections are dropped immediately.

Constants§

MAYBE_ZOOM_MIN_FRACTION
Fraction of the first MAYBE_ZOOM_WINDOW payload-bearing packets that must look like Zoom for the connection to be accepted.
MAYBE_ZOOM_MIN_PKTS
Minimum payload-bearing packets needed to judge a connection that ended before MAYBE_ZOOM_WINDOW was reached.
MAYBE_ZOOM_WINDOW
Number of payload-bearing packets inspected before making a decision.
ZOOM_FIRST_BYTES
First-byte values that mark a Zoom payload.
ZOOM_PORT_RANGE
UDP port range Zoom traffic is expected on.
